# 图谱详情作答评分设计

## 目标

在知识图谱详情页（`viewer/graph.html`、`viewer/app.js`）的“评估话术”下提供与知识脉络页相同的文本作答和 AI 评分体验。文本框兼容系统语音输入法。

## 范围

- 复用已有 `POST /api/assessment`、`scripts/llm-assessment.mjs` 与其瞬时失败重试策略。
- 图谱详情按当前路由主题 ID 提交 `{ topicId, answer }`。
- 显示分数、总体评价、做得好的地方、可以改进；答案失败后保留。
- 评分不读取或写入掌握状态；图谱详情原有掌握按钮行为不变。

## 界面与可访问性

仅当主题存在 `assessmentPrompt` 时，在评估话术框之后渲染具有关联标签的 `textarea`、提交按钮、学习参考提示和 `aria-live` 结果区。空文本保持焦点，不发请求。请求期间按钮禁用并显示评分状态。结果字段必须使用 HTML 转义后再渲染。

样式在 `viewer/style.css` 中限定至图谱详情使用的类名，并保持现有详情页、窄视口布局与色彩 token 一致。

## 验证

- 先增加图谱详情作答渲染和提交行为测试，确认在实现前失败。
- 实现后运行相关测试及完整 `npm test`。
- 用图谱路由 `#/mt_c29FaCTNsx?dim=us&tab=graph` 在浏览器确认：存在输入区、可提交并显示服务端评分、提交按钮恢复可用、掌握状态不改变。
