📄 用户协议(实验功能)

这是一个实验性功能,可能随时下线。

1. 数据只存你本地。你标记的知识点、孩子的画像信息(年龄、年级、地区等)全部只保存在你浏览器的 localStorage 里,不上传、不建账号、没有服务器数据库。换浏览器或清缓存即丢失。

2. AI 解析需要把你输入的文字发给大模型。点「AI 解析」时,你输入的描述(以及已有画像,用于理解语境)会发送给 DeepSeek API 处理,用完即弃。不要输入真实姓名、联系方式等敏感信息。

3. AI 结果仅供参考。知识点匹配与学习建议由 AI 推测,未经教师审核,不构成教育建议。

4. 你可以随时通过顶栏「清除数据」删除本地全部记录。
